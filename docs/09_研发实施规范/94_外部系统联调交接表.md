# 94 企业微信、有赞、医院、文件系统联调交接表

本表交由业务运营/IT/供应商负责人逐项补齐；**没有获取授权和接口规格之前只能开发 Adapter Mock，不得虚构供应商接口能力、真实 URL 和必需字段。**

## A. 企业微信（仅官方渠道，排除个人微信）

| 准备项 | 填写内容/责任 | 验证证据 |
|---|---|---|
| 企业主体及自建/第三方应用 | IT | 企业ID、应用类型 |
| 客户联系能力 | IT | 可获取客户和服务人员授权范围 |
| 会话内容存档 | IT/合规 | 已开通、启用成员、外部客户同意机制 |
| 存档 SDK 与秘钥 | IT安全 | SDK受支持环境、私钥托管路径/轮换 |
| 历史同步窗口、游标与限速 | 集成开发 | 实际 SDK 当前文档与测试采集 |
| 媒体内容 | 合规/IT | 支持类型、下载/存储限制 |
| 数据用途与保存期限 | 合规负责人 | 合同、告知同意、删除/撤回机制 |
| 客户身份映射 | 运营 | `external_user_id` 与 CRM 多身份合并策略 |
| 失败补偿 | IT | 超时、缺采告警、游标回补演练 |

## B. 有赞

| 准备项 | 填写内容/责任 | 验证证据 |
|---|---|---|
| 店铺产品/账号类型 | 运营 | 所在店铺及权限截图/说明 |
| 开放平台应用/授权 | IT | 可用接口目录，不交付明文密钥 |
| 订单/支付/退款订阅 | IT | 实际支持的事件与参数 |
| 商品 SKU 与套餐映射 | 产品运营 | 原 SKU ID、CRM sku_id 对照表 |
| 订单类型及活动批次 | 运营/财务 | 有赞字段到 CRM 字段映射，冲突优先级 |
| 线下/平台收款识别 | 财务 | 收款方、实际入账及对账凭证 |
| 补偿时间窗/分页限速 | IT | API 实测及频率限制 |
| 重试与验签 | 安全/研发 | 密钥轮换、验签失败处理 |

## C. 合作机构

| 准备项 | 决策要点 |
|---|---|
| 机构账号和人员权限 | 一个机构多个操作员；是否要“前台确认到院、运营确认核销、财务核对账单”三类权限 |
| 预约确认渠道 | 本系统机构端 / 机构外部 HIS 接口；两者事件冲突的主从策略 |
| 到院和服务凭证 | 服务时间、项目、核销次数、核销人、病例/签字附件的最小必要范围 |
| 退款/冲正流程 | 院方已核销但客户投诉时如何更正，不得直接删历史 |
| 结算协议 | 月结/次卡次结、线上/线下/点评佣金、税与保证金、保投产规则版本 |
| 机构合同附件 | 私有存储、预览/下载水印、签约日期、续签版本、审计 |
