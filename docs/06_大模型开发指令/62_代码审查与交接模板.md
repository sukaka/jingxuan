# 62 PR 评审 / 模块交接模板

## 1. PR 描述模板
```
# 功能：
对应原型页面 key 与路由：
对应 PRD/状态机/数据库表/权限：
涉及 Qxx 与ADR：
API 变更（路径/字段/错误码/版本）：
Kafka Event 变更（topic/schema version/兼容）：
Flyway 迁移编号/数据兼容/回滚：
前端组件与交互（空态/提交错误/禁用态）：
日志与审计：
后端数据隔离验证：
测试命令与真实输出：
风险/回滚/待处理：
```

## 2. reviewer 检查
- 各角色菜单可见与后端 resource scope 一致，机构不会读到其他医院。
- 资金/次数类型和事务边界明确；对应唯一键、幂等键、账本/Outbox/审计。
- 只新增允许的状态转换，非法直接跳转被拒绝。
- 客户昵称/手机号/企微身份映射未混淆；订单类型/活动批次、SKU规格/version 层次正确。
- API 生成的 TypeScript 客户端对应 OpenAPI，不存在猜字段。
- 新文件被扫描且私有，银行/聊天敏感日志脱敏，导出受限。
- 已确认核销、成功退款、合同审批生效历史没有直接修改/删除接口。
- 代码不包含假造的“真实有赞API”或“个人微信采集”；未启用场景有 Mock 与 FEATURE FLAG。
- 通过脚本在 `tests/` 跑到具体结果，无“我认为应该通过”的自述。

## 3. 交接 artifacts
代码仓库 commit SHA / release tag、Flyway 文件、更新后的 ER/字段字典、OpenAPI Event schemas、自动测试报告、Playwright截图/视频、部署清单、出错补偿指南、剩余 Qxx 列表和业务验收签字。
