# P2 实施接口约定（开发中）

本文件用于本轮并行开发对齐，不替代正式 PRD 与 OpenAPI。业务边界见根目录 AGENTS.md 与 `docs/00_项目管理/02_待确认事项与决策登记.md`。

## 已有结构

- V4 已有 `crm_campaign`、`crm_campaign_batch`、`crm_partner_channel`，禁止重复建表。
- V5 `crm_order` 已有 `campaign_id`、`campaign_batch_id`，创建订单已校验批次归属。V17 只补充销售时活动/批次/渠道快照，禁止覆盖历史值。
- `crm_partner_channel.business_owner_user_id` 是商务归因来源；新订单可显式保存渠道与成交时商务快照，不从当前客户来源或管家身份推断商务业绩。
- 文件已有 `MATERIAL`，默认要求机构；需新增受控的全局素材规则。服务端生成的导出文件分类为 `EXPORT`，必须私有、ClamAV CLEAN、限期下载，不沿用机构文件权限。

## V17 公共表约定

### 素材

`crm_material`：id、tenant_id、material_no、title、category_code、institution_id(nullable)、project_id(nullable)、city_code(nullable)、summary、tags_json、current_revision_id(nullable)、review_status(DRAFT/PENDING/APPROVED/REJECTED)、reviewer_id、created_by、created_at、updated_at、version。tenant+material_no 唯一，另建分类/机构/城市/项目/状态索引。

`crm_material_revision`：id、tenant_id、material_id、revision_no、title、summary、category_code、institution_id、project_id、city_code、tags_json、file_id、change_note、status(DRAFT/PENDING/APPROVED/REJECTED)、reviewer_id、review_note、reviewed_at、created_by、created_at、updated_at、version。tenant+material+revision_no 唯一，历史版本不覆盖。

### 导出

`crm_export_job`：id、tenant_id、job_no、requested_by、export_type(CUSTOMER/ORDER/REDEMPTION/FOLLOWUP)、status(PENDING/RUNNING/SUCCEEDED/FAILED)、filters_json、columns_json、scope_json、reason、row_count、file_id(nullable)、expires_at(nullable)、idempotency_key、request_hash、lease_owner(nullable)、lease_expires_at(nullable)、started_at(nullable)、finished_at(nullable)、last_error(nullable)、created_at、updated_at、version。tenant+requested_by+idempotency_key 唯一，另建状态租约索引。服务端保存已校验的字段与范围，不接受客户端放大范围。

`crm_export_access_log`：id、tenant_id、job_id(nullable)、actor_user_id、action(REQUEST/DOWNLOAD)、result(ALLOWED/DENIED)、reason、denial_code(nullable)、created_at。只追加，不记录敏感导出内容。

### 风控

`crm_risk_case`：id、tenant_id、risk_case_no、risk_type、severity(HIGH/MEDIUM/LOW)、source_type、source_ref、status(OPEN/ASSIGNED/RESOLVED/CLOSED)、owner_user_id(nullable)、evidence、resolution(nullable)、resolved_at(nullable)、created_at、updated_at、version。tenant+risk_case_no 唯一，tenant+source_type+source_ref+risk_type 唯一，状态/级别索引。

`crm_risk_case_history`：id、tenant_id、risk_case_id、action、from_status(nullable)、to_status、actor_user_id(nullable)、note(nullable)、created_at。只追加；风控无物理删除接口。

### 可追溯分析（可选保存，不是事实源）

`crm_daily_analytics` 按参考表：tenant+stat_date+dimension_type+dimension_ref+metric_code+metric_version 唯一，整数金额分、source_watermark。没有事实数据不得生成演示值。

`crm_performance_snapshot` 按参考表，另加 source_watermark、created_by；没有批准规则时目标为空/未配置，不将 PREVIEW 当工资或提成事实。

## API 约定

统一 `/api/v1`，返回现有 `ApiResponse`、错误码、分页格式，Controller 只做参数/权限入口，数据范围在 Application Service 和 SQL 强制。

- 报表：`GET /reports/operations`、`GET /reports/performance`、`GET /reports/sku-quality`；时间范围、时区、订单来源、口径版本、数据水位显式返回；Q13 比率 null + `PENDING_DEFINITION`。
- 活动：`GET/POST /campaigns`、`GET/PATCH /campaigns/{id}`、`POST /campaigns/{id}/batches`、`PATCH /campaigns/{id}/batches/{batchId}`；`GET /reports/campaigns` 可按前述报表模块提供。渠道：`GET/POST /channels`、`PATCH /channels/{id}`。
- 素材：`GET/POST /materials`、`GET/PATCH /materials/{id}`、`POST /materials/{id}/revisions`、`POST /materials/{id}/revisions/{revisionId}/submit`、`POST /materials/{id}/revisions/{revisionId}/review`、`GET /materials/{id}/revisions/{revisionId}/download`。
- 导出：`POST /exports`、`GET /exports`、`GET /exports/{id}`、`GET /exports/{id}/download`、`GET /exports/access-logs`。
- 风控：`GET /risks`、`GET /risks/{id}`、`POST /risks/{id}/claim`、`POST /risks/{id}/resolve`、`POST /risks/{id}/close`。request 带 version 和必要理由，非法跳转拒绝。
- SKU 质量只读真实订单行与 SKU/机构规则，低频不自动下架；积分沿用 `/customers/{id}/points`，不另建余额表。
