# 有赞云历史订单只读快照与微信服务号 H5 自动登录配置指南

本指南面向运营与运维人员，说明如何将刚注册的**有赞云自用型应用**与**已认证微信服务号**接入鲸选美学 CRM，实现：
1. 安全拉取有赞历史订单（商品标题、支付时间、实付金额）与买家名称、微信 `OpenID` / `UnionID` 盲索引到只读快照表（**不写入 `crm_order`，绝不触发权益发放**）；
2. 客户从公众号、朋友圈、微信群、有赞微商城 H5 或有赞小程序跳转推文进入统一入口 `/h5/annual-reports/entry` 时，**0.5 秒微信静默自动登录直达本人年终 H5**，且转发朋友圈绝不泄露原主人账单。

---

## 第一部分：有赞云自用型应用开通与拉取步骤（约 10 分钟）

### 第 1 步：创建自用型应用
1. 登录有赞云开发者控制台：`https://console.youzanyun.com/`。
2. 点击「应用管理」→「创建应用」→ 应用类型选择 **「无容器应用 · 自用型应用」**（仅对接自家店铺，无需上架应用市场，审核最快）。
3. 应用名称可填「鲸选美学 CRM 数据同步」，创建后进入应用详情页。

### 第 2 步：绑定授权自家有赞店铺并获取 3 个参数
1. 在应用详情页「授权管理 / 授权店铺」里，点击授权并扫码绑定你们的有赞店铺。
2. 记录下以下 **3 个核心参数**（切勿发到公开群或提交代码仓库）：
   - `client_id`（应用管理 → 应用设置）
   - `client_secret`（应用管理 → 应用设置）
   - `shop_id`（即有赞店铺 `kdt_id`，授权店铺列表中可查）

### 第 3 步：开通 4 个只读 API 权限
在有赞云应用的「能力管理 / API 权限」中搜索并开通以下 4 个官方接口：

| 序号 | 接口名称 | 版本 | 用途 | 是否必开 |
|---|---|---|---|---|
| 1 | `youzan.trades.sold.get` | `4.0.2` | 按时间窗拉取全年成交订单列表（代码自动按 ≤89 天切窗） | **必开** |
| 2 | `youzan.trade.get` | `4.0.2` | 补拉单笔订单完整商品明细与标题 | **必开** |
| 3 | `youzan.users.info.query` | `1.0.0` | 按 `yz_open_id` 查微信 `weixin_open_id`、`union_id`、昵称、手机号（**微信自动登录的核心钥匙**） | **强烈建议开通** |
| 4 | `youzan.scrm.customer.get` | `3.0.0` | 按手机号 `mobile` 或订单 `fans_type` + `fans_id` 查有赞 SCRM 客户姓名、手机号与性别（实测有赞云网关仅该版本有效，可解决部分新客昵称显示“微信用户”的问题） | 建议开通 |

> 若前期只批下了前 2 个订单接口、后 2 个仍在审核中，CRM 依然可以先把历史订单拉回只读快照表，结果里会提示尚未开通的买家接口，待审核通过后再重拉一次即可自动补全。
>
> **扩展说明（有赞客户拉取与 CRM 正式建档）**：如需在「集成中心 → 有赞订单同步 → 客户拉取与建档」将有赞客户批量建档为 CRM 正式客户，可直接使用「按有赞订单买家拉取（`ORDER_BUYERS`）」复用上述 4 个接口；若需拉取含未下单潜客在内的全量客户（`SCRM_LIST`），可额外在有赞云开通 `youzan.scrm.customer.search`（`3.1.2`，自动兼容 `3.1.1`/`3.1.0`）。详细断点游标、防重与手机号冲突规则见 [42_有赞订单对接.md](../04_接口与集成/42_有赞订单对接.md)。

**实测对接注意事项（基于有赞云店铺实测验证）：**
- **`youzan.users.info.query`（`1.0.0`）参数与 `union_id` 差异**：CRM 固定以 `result_type_list: [0, 1, 2, 9]` 调用该接口，并从返回体 `platform_info` 解析 `weixin_open_id`、从 `wechat_info` / `platform_info` 解析 `union_id`。未绑定微信开放平台同主体账号的**测试店铺**不会返回 `union_id`（属正常现象）；**生产店铺**绑定同主体微信服务号/小程序后即可正常返回 `union_id`。
- **订单隐私密文（`$...$1$`）自动过滤与补全**：`youzan.trades.sold.get` / `youzan.trade.get` 返回的 `fans_nickname`、`buyer_phone` 等字段可能为有赞安全密文（`$...$1$` 格式）。CRM 会自动忽略密文字串避免污染展示称呼或手机号，并改由 `youzan.users.info.query`（`1.0.0`）与 `youzan.scrm.customer.get`（`3.0.0`）自动补全明文昵称、姓名与手机号（手机号仍以盲索引存储）。

### 第 4 步：在 CRM 后台填入店铺授权并一键拉取只读快照
1. 使用具备 `integration:youzan:manage` 权限的管理员账号登录 CRM。
2. 进入 **「集成中心 → 有赞订单同步」**，填写 `shop_id`、`client_id`、`client_secret` 并点击「测试连接」（确保租户级真实有赞开关 `youzanRealEnabled` 已开启）。
3. 进入 **「客户管理 → 年终盘点 H5」**，在顶部「有赞历史订单只读快照与微信免密统一入口」卡片中点击 **「拉取有赞历史快照」**：
   - 输入 `shop_id` 与起止日期（如 `2026-01-01` 至 `2026-12-31`），勾选「补全买家信息」；
   - 点击开始拉取后，点击「有赞买家镜像」即可查看已同步的脱敏称呼、OpenID/UnionID 覆盖率与订单数。

## 第二部分：已认证微信服务号静默自动登录配置（不顶掉有赞授权！）

> **兼容性保障**：CRM 仅调用微信网页用户授权接口 `/sns/oauth2/access_token`（`scope=snsapi_base`），**绝不调用服务号全局 `/cgi-bin/token`**，因此**不会与已授权给有赞第三方平台的服务号产生任何 Token 冲突**。

### 第 1 步：在微信公众平台配置网页授权域名
1. 登录微信公众平台（`mp.weixin.qq.com`）进入你们的**已认证服务号**。
2. 菜单：**设置与开发 → 账号设置 → 功能设置 → 网页授权域名**（微信服务号允许配置 2 个域名，不影响原有有赞配置）。
3. 下载微信提供的校验文件 `MP_verify_xxxxxx.txt`，放到 CRM 生产公网 Nginx 网站根目录（确保 `https://<CRM域名>/MP_verify_xxxxxx.txt` 可直接访问）后保存。
4. 在 **设置与开发 → 基本配置** 中记下服务号的 `AppID` 与 `AppSecret`（注意：不需要修改服务器配置/开发者密码以外的任何第三方授权开关）。

### 第 2 步：配置 CRM 生产环境变量
在 CRM 后端服务 `.env` 或容器环境变量中配置如下参数并重启 `crm-api`：

```bash
# CRM 对外公网域名（HTTPS，不带末尾斜杠）
ANNUAL_H5_PUBLIC_ORIGIN=https://crm.your-domain.com

# 开启微信服务号静默自动登录（snsapi_base）
ANNUAL_H5_WECHAT_MP_ENABLED=true
ANNUAL_H5_WECHAT_MP_APP_ID=wx你的服务号AppID
ANNUAL_H5_WECHAT_MP_APP_SECRET=你的服务号AppSecret
ANNUAL_H5_WECHAT_MP_CALLBACK_URL=https://crm.your-domain.com/api/v1/public/annual-reports/auth/wechat/callback

# 手机号验证码兜底开关（前期零成本保持 DISABLED；未来买好短信通道后改 WEBHOOK 并配下方地址）
ANNUAL_H5_SMS_MODE=DISABLED
# ANNUAL_H5_SMS_WEBHOOK_URL=https://your-sms-gateway/send
# ANNUAL_H5_SMS_WEBHOOK_TOKEN=your-bearer-token
```

## 第三部分：各渠道投放挂法速查

| 投放渠道 | 挂载方式 | 客户打开体验 |
|---|---|---|
| **公众号菜单 / 推文 / 微信群** | 直接挂统一入口：`https://你的CRM域名/h5/annual-reports/entry?year=2026` | 0.5 秒微信静默授权，自动进入**本人**年终 H5 |
| **有赞托管商城小程序** | 首页/个人中心放活动图 → 跳**同主体服务号推文**（推文内放统一入口），或在微商城 H5 页直接放统一入口链接 | 0 定制费，避开微信标准小程序外链拦截，同样自动识别本人 |
| **朋友圈海报 / 裂变转发** | 客户在 H5 末页保存 PNG 海报或点「复制朋友圈安全入口」（统一指向 `/entry`） | 朋友打开自动识别为**朋友自己**的身份，绝不泄露原主人消费记录 |
| **企微管家 1v1 发高客单老客** | 在 CRM「年终盘点 H5」页生成并复制 43 位 `shareKey` 专属链接发给客户 | 点击零跳转直达本人冻结快照；若客户保存海报发圈仍自动走安全统一入口 |
