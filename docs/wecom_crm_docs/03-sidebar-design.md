# 03. CRM 侧边栏设计

## 1. 目标

员工在企业微信聊天中不离开当前页面即可：看客户、看套餐、查剩余、看核销、创建预约/回访/待办、使用快捷话术、获取 AI 建议。

## 2. 页面结构

```text
┌────────────────────────┐
│ 王女士            VIP   │
│ 138****1234            │
│ 管家：张三              │
├────────────────────────┤
│ 客户 | 套餐 | 跟进 | AI | 工具 │
├────────────────────────┤
│      当前Tab内容        │
└────────────────────────┘
```

## 3. 客户 Tab

姓名、手机号（默认脱敏）、等级、渠道、机构、当前管家、商务、标签、最近到院、最近消费、累计消费、创建时间。

## 4. 套餐 Tab

每个套餐展示：项目、购买次数、已用、剩余、有效期、订单状态、退款状态、最近核销；提供“发送剩余次数”“创建预约”。

## 5. 跟进 Tab

展示跟进、回访、预约、到院、核销、退款、待办；支持创建回访、预约、待办、新增跟进。

## 6. AI Tab

AI 客户摘要、当前意图、推荐回复、风险提示、回访建议、复购建议。支持重新生成、编辑、复制、发送。

## 7. 工具 Tab

查剩余、发项目、发地址、发预约、术前须知、术后须知、回访问候、复购提醒、AI 推荐回复。

## 8. 窄屏要求

适配 320-520px；不使用宽表格，多用卡片，二级信息折叠，关键数字突出，底部操作固定。

## 9. 页面状态

必须覆盖 Loading、客户未关联、客户无套餐、权限不足、企业微信异常、AI 异常、普通浏览器访问、非聊天工具栏入口。


## 10. V47 H5 卡片与公开页

工具 Tab 分为“快捷话术 / H5 卡片”。卡片编辑器支持 ACTIVE 项目选择、标题、摘要、公开介绍、即时卡片预览、公开页检查、复制链接、当前单聊发送、本人历史与链接停用。修改已生成内容会清除旧快照，必须重新生成，避免表单与发送内容不一致。

公开路由为 `/h5/cards/:shareKey`，不使用后台外壳，不要求登录，并设置 `noindex,nofollow,noarchive`。页面只展示项目公开快照，明确不构成诊断、疗效承诺或订单凭证；加载、失效和停用状态分别处理。所有正文使用纯文本插值，不渲染 HTML。

卡片发送复用 `sendChatMessage` 的 `news` 结构，沿用 320–520px 窄屏和人工确认边界；真实企微环境未验收前不宣称线上卡片展示通过。
