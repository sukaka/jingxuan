# 10. 测试计划与验收标准

## 1. P0 正向验收

员工打开客户聊天 -> 打开 CRM 工具栏 -> 免登录 -> 正确员工 -> 正确客户 -> 映射 CRM -> 客户档案 -> 套餐/剩余 -> 选择话术 -> 动态渲染 -> 预览 -> 编辑 -> 确认 -> 当前会话发送 -> 发送日志入库。

## 2. P0 异常

客户未关联、Token 过期、JS-SDK 签名失败、普通浏览器、非聊天工具栏、无权限、变量缺失、套餐不存在、客户转接、员工离职、网络中断、企业微信超时、重复点击发送、发送与日志状态不一致。

## 3. 快捷话术

固定/动态、多变量、必填变量为空、特殊字符、超长文本、XSS 输入、编辑后发送、作用域过滤、收藏、最近使用。

## 4. AI

不编造次数/金额、FACTS 缺失不猜、JSON 稳定、AI 超时降级、不可写业务表、不可自动发送。

## 5. 会话存档

文本、图片、语音、视频、文件、撤回、客户不同意、员工不在范围、SDK 异常、重复拉取、cursor 恢复、乱序、媒体失败、Kafka 重试、幂等。

## 6. 性能建议

侧边栏骨架 1 秒内显示；核心信息约 2 秒内可用；快捷话术查询/预览尽量 <500ms；AI 可异步，失败不影响基础功能。

## 7. 安全

越权、IDOR、CSRF、XSS、SQL 注入、Secret 泄漏、token 日志泄漏、Session/JWT 重放。


## 8. V51 群聊验收矩阵

- 未登记群、清单停用、未知/已退出发送人、无外部参与人、无可采员工、任一当前外部参与人未同意：均不得保存正文，并产生可定位缺口。
- 完整清单新增、重放、过期 version、缺 CSRF、越权修改：必须分别符合幂等、冲突、安全拒绝与审计要求。
- 群消息不关联单一客户，实际员工/外部发送人正确，文本、媒体、撤回先到和原消息后到均兼容。
- 管理员、团队员工、本人和无关员工的列表/正文/媒体访问按 SQL 数据范围隔离；参与人退出影响新采集但不删除历史；历史参与人撤回同意后禁止继续读取。
- V51 全量 Flyway 迁移与逆序回滚，既有单聊、Mock/官方游标、AI 安全边界与前端会话展示必须回归。真实企业成员清单与线上权限另行验收。


## 9. V53 运营分析验收矩阵

- 快捷话术分别覆盖 COPIED、SDK_SUCCESS、SDK_FAILED、SDK_UNKNOWN、编辑和 AI 关联，SDK 成功率不包含复制分母。
- AI 候选覆盖生成、采纳、驳回、待处理、编辑采纳、Mock 提供方，采纳率只使用期内创建批次；候选复制/SDK 与采纳分开。
- 同一确认预约批次必须有真实 CHECKED_IN 才计到院，未到院/其他机构/越权客户不混入；只有创建或计划到院不算实际到院。
- 同一订单多个 CONFIRMED 支付流水只计一笔，PENDING/FAILED 不计；期内付费客户和多次付费客户分别计算，无分母比率为 null。
- 验证 ALL/TEAM/SELF、员工筛选、匿名/机构/跨员工拒绝、日期倒序和超长期限；前端失败必须清空旧指标，不展示原始英文能力代码。
- 不生成 H5 已读、客户已读或聊天因果归因；真实业务转化与模型质量需生产数据另行验收。
