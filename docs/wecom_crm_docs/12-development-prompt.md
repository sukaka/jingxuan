# 12. 大模型开发总 Prompt

你正在开发“企业微信客户联系 + 医美 CRM 侧边栏 + 快捷话术 + AI 助手”系统。严格遵守 `docs/` 下设计文档。

## 核心原则

1. 企业微信负责客户聊天，CRM 通过聊天工具栏提供客户侧边栏。
2. 只使用企业微信官方 API、JS-SDK、OAuth、客户联系和会话内容存档能力。
3. 严禁个人微信 Hook、企业微信客户端注入、协议逆向、非官方聊天采集。
4. 普通客户联系消息必须由员工在当前聊天上下文中确认发送。
5. 后台任务不得冒充员工任意发普通客户消息。
6. `external_userid` 不得作为 CRM 主键。
7. AI 不得产生或修改业务事实。
8. 金额、次数、时间、订单、退款、核销、预约必须来自数据库。
9. 企业微信接口在实现前必须核对官方当前文档，不允许凭记忆猜接口。

## P0

OAuth、JS-SDK、聊天上下文、external_userid、客户映射、客户档案、套餐/核销/剩余次数、快捷话术、动态变量 Resolver、预览、编辑、当前会话发送、发送日志。

不要在 P0 做会话存档、复杂 AI 自动事件、大规模统计、自动营销和自动发消息。

## 技术要求

Java 17+ / Spring Boot 3.x；Vue 3 + TypeScript；MySQL 8；Redis；Kafka 预留；企业微信 SDK 独立封装；migration；Service/API/Integration Test。

## 禁止事项

禁止前端保存 Secret、写死 access_token、写死话术/机构/渠道/标签、前端绕过权限、AI 直接写订单/退款/核销、AI 自动发送、用昵称头像自动合并客户、发明企业微信接口。

## 每次开发流程

1. 更新代码
2. migration
3. 补测试
4. 更新 progress 文档
5. 记录重要 ADR
6. 说明影响范围
7. 执行测试
8. 汇报结果

严格 P0 -> P1 -> P2 -> P3。优先复用已有客户、机构、产品、套餐、渠道、订单、核销、退款、回访、管家、商务、权限模块。
