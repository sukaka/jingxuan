# 01. 业务需求

## 1. 用户角色

- 管家：客户沟通、项目提醒、预约、回访、核销协助、复购。
- 商务：客户来源、机构、成交、订单、商务业绩。
- 客服：咨询、售后、投诉、预约协助。
- 机构管理员：本机构客户、人员、订单、核销、回访。
- 总部管理员：全局管理机构、话术、权限、统计。
- 系统管理员：企业微信应用、接口、密钥、任务、日志配置。

## 2. 核心场景

### 查询套餐剩余次数
客户询问剩余项目时，侧边栏自动识别客户、查询套餐、展示已购/已用/剩余，推荐动态话术，员工预览/修改后发送。

### 预约
查看最近项目 -> 创建预约 -> 选择机构/时间/项目 -> 保存 -> 自动生成预约确认话术 -> 员工确认发送。

### 术后回访
根据最近核销和回访规则生成提醒，员工查看客户情况并发送回访话术，保存结果。

### 复购
套餐剩余较少或已用完，规则引擎/AI 生成复购建议，由员工确认后发送。
