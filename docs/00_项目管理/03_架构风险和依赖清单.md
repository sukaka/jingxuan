# 03 风险、依赖与外部接口就绪检查

## 风险登记
| 风险 | 概率/影响（建议） | 缓解措施 | 判定标准 |
|---|---|---|---|
| 有赞应用未有权限 | 中/高 | Mock Adapter/补偿同步/人工映射 | 提供可用店铺与真实API测试凭据 |
| 企微会话存档未开通 | 中/高 | CRM业务独立可用，先人工跟进 | 成员授权、客户同意与SDK联调通过 |
| 旧套餐规则不全 | 高/高 | 禁止不明确规则自动发权益 | SKU/套餐子项目/次数/金额分摊签字 |
| 机构财务口径不统一 | 高/高 | 单独资金流、待核对账单 | 财务确定收款主体/费率基数/退款算法 |
| 原智能表格脏数据 | 高/中 | 源数据副本、人工合并、差异对账 | 关键数据迁移签字 |
| AI编码大范围改动 | 高/中 | 分阶段Task卡+PR限制+CI | 每个阶段独立验收，有可回滚提交 |
| Redis/Kafka运维成本 | 中/中 | 单机开发/隔离生产，监控和托管选项 | RPO/RTO演练、故障告警 |
| 敏感医疗/支付信息泄露 | 中/极高 | 后端行级权限/脱敏/密钥/安全测试 | 安全审查和权限渗透测试 |

## 外部平台对接就绪表
| 依赖 | 需要从业务/平台获得 | 未获得时替代 |
|---|---|---|
| 企业微信 | CorpID、应用授权、联系人权限、归档许可、SDK密钥、成员范围、客户授权约定 | MockWecomAdapter + 人工沟通填报 |
| 有赞 | 店铺ID、应用类型、接口授权、测试账号、商品SKU字段、订单/退款通知 | MockYouzanAdapter + CSV导入 |
| 合作医院 | 机构账号、授权角色、服务/核销流程与凭证要求 | 机构Web工作台 |
| AI模型 | 供应商或本地模型、安全/保留策略、限额、调用凭据 | 关闭AI，人工创建待办 |
| 银行/支付 | 收款主体/支付确认回执/退款结果 | 仅有权限财务审核线下凭证 |

## 研发阻断标准
尚未确认的账务规则不得让工程师“按常识自动计算”。缺接口权限不得填入猜测 endpoint。没有资质/授权不得从个人微信获取内容。不能以“前端能操作”视为真实 DB 已正确、权限已正确。
