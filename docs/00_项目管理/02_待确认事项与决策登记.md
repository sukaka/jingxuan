# 02 待确认事项与决策登记（绝不能由 AI 猜）

| 编号 | 待确认问题 | 推荐安全默认值 | 责任角色 | 阻断环节 |
|---|---|---|---|---|
| Q01 | 「选3项」是否可跨子项目自由组合、可否重复选、每项次数 | 仅创建模板，**不自动发放**未明确的权益 | 运营 | 正式权益发放 |
| Q02 | 套餐多个子项目实付金额如何分摊，是否按单价比例/固定价 | 使用配置的分摊权重；无规则则标“待分摊”，不可计算机构应结 | 财务+运营 | 核销金额/结算 |
| Q03 | 跨机构使用套餐、医院变更是否需要复核 | 仅允许明确关联并在有效期内的机构 | 运营+机构 | 医院核销 |
| Q04 | 机构结算（月结/次卡次结）计费周期、含税/税率/佣金计算基数 | 不自动结算，进入待确认清单 | 财务+商务 | 机构账单 |
| Q05 | 平台收款与医院收款时的收支模型、发票和账期归属 | 区分收款方；不把医院代收当平台实收 | 财务 | 财务报表 |
| Q06 | 部分退款、已消费退款、优惠券/赠送权益回收规则 | 审批人工确定项目、次数和金额，不自动比例推断 | 财务 | 退款完成 |
| Q07 | 复购业绩归哪个管家/商务：成交时还是归属变更后 | 保存成交快照；口径开关待批 | 业务主管+财务 | 业绩统计 |
| Q08 | 市场审核/财务审核字段清单、是否同人可双审 | 最小权限；申请人与审核人必须不同；敏感字段双审 | 市场+财务 | 机构资料生效 |
| Q09 | CRM 组织架构/团队负责人/转交审批条件 | 默认同组主管审批跨人转交，跨组管理员审批 | 人事+运营 | 客户归属 |
| Q10 | 企微会话存档资质、涉及成员范围、授权/同意、数据保存期限 | 未具备条件时不采集、不展示聊天全文 | 法务+IT | 真实会话存档 SDK、聊天正文采集与展示（不阻断官方客户资料 API） |
| Q11 | 有赞店铺产品类型、开放平台权限、订单订阅/退款订阅、接口限流 | `MockYouzanAdapter`，真实 API 禁用 | IT+运营 | 自动同步 |
| Q12 | S/A/B/C 定义、消费能力阈值、客户积分规则与生日用途 | 标签人工维护；积分只允许后台审核调整 | 运营 | 积分自动计算 |
| Q13 | 触达、面诊、到院、核销、净业绩、大促转化率统计分母 | 先展示口径描述，禁止虚构比率 | 运营+财务 | 经营报表 |
| Q14 | 导出数据范围与字段屏蔽、员工离职回收权限 | 普通管家默认禁止批量导出/复制敏感字段 | 安全+业务 | 导出中心 |
| Q15 | 原 23 字段中带公式标识字段的真实计算公式与原表关联 | 按原值保留 `legacy_value`，新口径单独计算 | 运营+IT | 旧数据迁移 |
| Q16 | 旧“客户来源”与“客户渠道”区别/达人成交归因 | 两字段独立并保留历史原值 | 市场 | 渠道分析 |
| Q17 | 医院服务签收凭证、院方最终确认人、异常更正审批 | 院方确认，冲正须主管复核 | 机构+运营 | 正式核销 |
| Q18 | 合同/证照/病例素材保存时限、下载水印/审批 | 最小权限+私有文件桶+审计，实际保留期待定 | 法务+安全 | 文件正式上线 |
| Q19 | Dify 部署版本、云服务或私有化、Embedding/生成模型、凭据、网络及数据保留/跨境政策 | `FEATURE_REAL_DIFY=false`；只用 Mock 或模拟 HTTP，不发送真实请求 | IT+安全+法务 | 真实 Dify 连接测试、真实问答及生产启用 |
| Q20 | 可进入知识库的资料分类、发布/提问角色、机构范围和问答内容保留期限 | 不发布客户聊天、健康、交易、合同或银行资料；默认不开放知识发布 | 运营+安全+法务 | Dataset 资料同步、正式知识问答与会话保留 |
| Q21 | 生产容量目标、预发/生产环境、真实凭据、渗透范围及灰度/回滚批准 | 只做本机合成数据与 Mock 冒烟；不启用真实渠道，不部署生产 | IT+安全+业务负责人 | 生产容量验收、渗透、部署、灰度与回滚 |
| Q22 | Spring Web MVC 两项 CVE 的兼容修复版本，或是否评审升级 Boot 4 / Spring 7 | 不把 Spring 7 单独混入 Boot 3.5；OSV 保持 FAIL，不以未使用相关功能代替修复 | IT+安全 | 依赖漏洞关闭与生产安全放行 |

## 给 AI 的强制规则
若任务依赖未决 Qxx，不得凭经验给出生产金额/资格/审批结论。应为规则留配置表、待确认状态和阻断动作；在 PR 摘要明确说明未定风险。不得把本文的“安全默认值”误写成业务部门既定政策。
