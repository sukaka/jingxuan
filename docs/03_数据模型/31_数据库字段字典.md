### `crm_dify_knowledge_config` — 每租户独立 Dify Chatflow 配置

| 字段 | MySQL 类型 | 说明 |
|---|---|---|
| `tenant_id` | `BIGINT UNSIGNED NOT NULL` | 企业/租户，每租户一条 |

回滚：先关闭租户知识配置与 `FEATURE_REAL_DIFY`，下线菜单、Controller、Service 和 Worker 路由，确认无调用后删除 `ai:knowledge:config` 角色权限/权限及本表；再回滚 V20 代码。不得改动 `crm_ai_provider_config` 或既有 AI_JOB/洞察。若已有配置数据，先导出不含密钥的映射并单独执行密钥销毁，不允许为回滚而删除其他 AI 历史。

## P2-KB-2 资料发布与 Dataset 同步（V21）

`crm_dify_knowledge_config` 增量字段：`dataset_id VARCHAR(128) NULL`（显式 Dataset 映射）、`dataset_api_key_cipher TEXT NULL`（独立 AES-GCM 密文）、`sync_enabled TINYINT(1) NOT NULL DEFAULT 0`（资料同步开关）。启用 Dify 同步必须同时具有 Dataset ID 和 Dataset Key；App Key 与 Dataset Key 不混用。

### `crm_knowledge_document` — 素材到 Dify 的当前发布映射

| 字段 | MySQL 类型 | 说明 |
|---|---|---|
| `material_id` | `BIGINT UNSIGNED NOT NULL` | 素材，每素材一条当前映射 |
| `active_revision_id` | `BIGINT UNSIGNED NULL` | 当前可检索修订，索引成功后才更新 |
| `dataset_id / dify_document_id` | `VARCHAR(128) NULL` | 当前 Dataset/document 映射 |
| `status` | `VARCHAR(32) NOT NULL` | `WAITING/SYNCING/ACTIVE/FAILED/DISABLED` |
| `published_by / published_at` | `BIGINT / DATETIME(3)` | 首次发布人与最近索引成功时间 |

唯一键：`tenant_id + material_id`；状态索引：`tenant_id + status + id`。`active_revision_id` 在新版本索引成功前保持旧值。

### `crm_knowledge_sync_job` — 知识资料异步同步任务

| 字段 | MySQL 类型 | 说明 |
|---|---|---|
| `document_id / revision_id` | `BIGINT UNSIGNED NOT NULL` | 发布映射与拟发布修订 |
| `content_hash` | `CHAR(64) NOT NULL` | 源文件 SHA-256，不保存正文 |
| `status` | `VARCHAR(32) NOT NULL` | `WAITING/PENDING/RUNNING/INDEXING/RETRY/SUCCEEDED/FAILED` |
| `attempt_count / max_attempts` | `INT UNSIGNED` | 已执行次数与上限，默认 0/5 |
| `next_retry_at / lease_owner / lease_expires_at` | `DATETIME(3) / VARCHAR(128) / DATETIME(3)` | 有界重试与执行租约 |
| `dify_document_id / dify_batch` | `VARCHAR(128) NULL` | 外部文档和索引批次 |
| `last_error_masked` | `VARCHAR(500) NULL` | 脱敏错误，不含正文或密钥 |
| `requested_by / idempotency_key / request_hash` | `BIGINT / VARCHAR(128) / CHAR(64)` | 发布人、幂等键与规范化请求哈希 |
| `started_at / finished_at` | `DATETIME(3) NULL` | 首次执行与最终完成时间 |

唯一键：`tenant_id + document_id + revision_id + content_hash`、`tenant_id + requested_by + idempotency_key`；认领索引：`tenant_id + status + next_retry_at + lease_expires_at + id`。新权限 `ai:knowledge:read`、`ai:knowledge:publish` 默认仅 ADMIN，素材读/写/审核权限不隐式获得发布权。

回滚：先停用同步、Kafka consumer 和 Worker，等待在途任务结束；保留下载/审计所需的只读映射后，按 `crm_knowledge_sync_job → crm_knowledge_document` 顺序处理任务，再移除新权限和 V21 配置列。不得删除素材审核版本，不得回滚为知识事件落入订单 topic，不得改动既有 AI/交易表。
